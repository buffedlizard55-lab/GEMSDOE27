# Generative-AI disclosure

The code, analysis, documentation and site in this repository were produced by an AI agent (Arena.ai Agent Mode) working in the owner's repository, under the owner's instructions.
The Official Rules (Sept 2026, https://docs.nlr.gov/docs/fy26osti/96647.pdf, read in part) state that generative-AI use is allowed but must be stated in the narrative; the owner should include an equivalent statement in the final-round narrative.

What the agent did: re-implemented the metric/thinning/holdout conventions; built the fault-graph, link-candidate and verification code; ran and recorded the validations (including one disclosed implementation bug and its rerun);
wrote the knowledge base and site. What the agent did not do: access drivendata.org, submit any file, read or invent any leaderboard score, or train on any label that was hidden in a validation fold.
Human judgment still required: whether to submit, interpretation of geology by a qualified geologist, and the final-round narrative.
