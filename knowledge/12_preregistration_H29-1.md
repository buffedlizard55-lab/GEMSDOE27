## 2. Frozen evaluation design

- **Selected candidate:** H29-1 only. Do not tune thresholds, substitute H29-2/H29-3, or repeat seeds after seeing outcomes.
- **Baseline:** same-run H28-1 OOF detector (32 cached label-free features + six H28 magnetic/gravity edge features), H27-4 100 m flank-shadow pruning, and the existing T-v2 z≥3 topology additions, all evaluated on the same four quadrants and same seed/fold splits. This is the strongest documented paired holdout recipe in this checkout, not a leaderboard score.
- **Seeds:** 160–169 inclusive, 40 fold/seed cells. A repository-wide search on 2026-10-25 found no prior use of this range in registered holdout outputs. These seeds are consumed by this test even if the result is negative.
- **Withholding and buffer:** hide whole 8-connected fault components in the test quadrant. Keep `known` as the pixel-exact visible-label score mask. For every catalogue-derived feature, use `feature_known`, which excludes visible catalogue pixels within a 3-pixel (300 m) Euclidean buffer of withheld components. Build the graph exclusively from `feature_known`; all link evidence (including endpoint tangents and local strike support) is recomputed from this visible/buffered graph. Feature-generation code must not read withheld label values.
- **Candidate construction:** generate links with the existing frozen T-v2 cone (30°), distance range 10–40 pixels (1–4 km), spacing 3 pixels, evidence score z≥3, and mutual-link deduplication. Retain a link only when another eligible link has a distinct unordered component pair, distinct endpoints, midpoint distance ≤5 pixels, and axial-strike difference ≤15°. Do not count a reciprocal A→B/B→A link as its own corroborator. Candidate dots must be inside the footprint, off all visible catalogue cells, and ≥3 pixels from the same-run baseline dots before adding.
- **Leakage canary:** score the binary H29-1 feature alone against hidden positives versus the active test-fold footprint for every cell. Report the area-weighted pooled ROC AUC and every fold AUC. If any valid pooled/fold AUC exceeds 0.90, classify as leakage until demonstrated otherwise and stop; no TIFF is eligible.
- **Metric:** pooled distance-weighted Tversky index, α=0.2, β=0.8, 300 m triangular kernel, exact 100 m grid. Mask all visible labels pixel-exactly; the 300 m buffer is for feature generation only. Report evaluator source/version hash, withheld positive count, mean paired DTI difference and a seed-cluster bootstrap 95% CI (10,000 resamples of the 10 seed-level fold-mean differences, fixed bootstrap seed 20261025). This catalogue-internal holdout is not test-set truth.
- **Promotion gate (all required):** mean paired ΔDTI ≥ +0.001; at least 3/4 fold means and 8/10 seed means positive; lower 95% CI >0; no feature-alone AUC >0.90; all artifact/grid/range checks pass; and pre-placement and final raster pass the registry-duplicate guard. Passing only validates the experiment; it does not select a weekly slot or establish an organizer score.
- **Uniqueness lane guard:** compare rank-correlation and candidate-dot fraction within 3 pixels against each available submission raster from GEMSDOE24/25/27/28/30/31/32/33/36, using the candidate surface before placement and the final raster after generation. A correlation >0.90 **or** >70% of candidate dots within 3 pixels of any one registry raster means duplicate: record it and stop. If any site's registry corpus cannot be obtained or compared, the final verdict is `negative` / not submit-eligible.
- **Artifact policy:** never overwrite a weekly slot. If the validation or uniqueness gates fail, any generated GeoTIFF is a `research-negative / DO NOT SUBMIT` artifact in a separate research directory; if they pass, still keep it unselected until the separate slot selector acts. No site or API is permitted to auto-submit it.

## 3. Non-fault process that could mimic the signal

Drainage/canyon lineaments or map-digitisation snapping can produce apparent collinear continuations and clustered fault-tip geometry without an unrecorded fault. Because the candidate uses fault-catalogue topology rather than independent geology, this is a material confounder; a holdout win would not establish a physical fault or geothermal vent.
