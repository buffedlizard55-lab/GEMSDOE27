Step 2 — verify the file locally before upload

The validator checks:

  • single-band float32 GeoTIFF
  • CRS EPSG:32611, shape (3730, 3292), transform matching the template
  • values in [0, 1] inside footprint; zeros outside (all-finite variant; NaN-outside can trigger “Predicted values must be in range [0, 1]”)
  • no NaN or infinities

Run locally:

python scripts/build_h_geo_1_submission.py --validate-only

Step 4 — manual portal upload

  1. Open the competition page.
  2. Check the weekly-slot calendar for an open slot (slot_a Oct 30 is open in our local notes; verify on the portal).
  3. Upload the exact allfinite.tif file (or its one-TIFF ZIP) with the submission name and note above.
  4. Record the organizer receipt: slot id, submission id, submitted-at, and scored value once available.

Step 5 — label every number honestly

  • HOLDOUT-DTI = evaluator version with withheld positives and 95% CI (never project it onto the organizer score)
  • ORGANIZER-CONFIRMED = receipt received through the portal
  • Owner-reported values (e.g. GEMSDOE32 0.2778, H31-1 0.2250) are neither HOLDOUT-DTI nor ORGANIZER-CONFIRMED
