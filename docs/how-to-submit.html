3. Preventing the reported “Predicted values must be in range [0, 1]” error

  • Root cause 1 (NaN outside footprint): sample_submission.tif contains 7,111,787 NaN pixels outside the irregular 5,167,373-pixel study footprint. Under IEEE-754 floating-point semantics, a strict validator evaluating ((arr >= 0.0) & (arr <= 1.0)).all() returns False if any NaN exists anywhere in the 3730×3292 array. Official reference notebook Cell 19 (drivendataorg/gems-prize-reference-solution) initializes y_out = np.zeros(...) with nodata=None.
  • Root cause 2 (Float32 sentinel bleed): raw training_features.tif stores -3.4028235e+38 sentinels on 3,061 cells inside the valid footprint; unclipped linear or sigmoid pipelines propagate out-of-range values.
  • Historical H31-1 artifact only (not authorized for submission): its saved machine receipt records gems27-h31-drcg-wl-celf28-20261026-cf8e1bbef244-allfinite.tif as single-band float32, EPSG:32611, shape (3730, 3292), transform (100.0, 0.0, 243350.0, 0.0, -100.0, 4508550.0), nodata=None, 0 NaNs and 0 Infs across all 12,279,160 pixels, and value set strictly {0.0, 1.0} (machine validator JSON receipt).
